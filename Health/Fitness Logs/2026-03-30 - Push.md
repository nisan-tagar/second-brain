### 🟦 Week A: The "Shoulder Priority" Push Day

This structure prioritizes your overhead strength by performing it first.

| Done | Exercise                           | Sets | Reps  | Weight | Notes / Rationale                                                                                                            |
| ---- | ---------------------------------- | ---- | ----- | ------ | ---------------------------------------------------------------------------------------------------------------------------- |
| [ ]  | **1. Overhead Press (Barbell/DB)** | 4    | 6-8   |        | **Done first for maximum strength.** Your shoulders and triceps are fresh, allowing for true progressive overload.           |
| [ ]  | **2. Incline Dumbbell Press**      | 3    | 8-10  |        | A perfect second exercise. It targets the upper chest and front delts without the systemic fatigue of a heavy barbell press. |
| [ ]  | **3. Machine Chest Press**         | 3    | 10-12 |        | **Safer, stable alternative.** After two free-weight presses, a machine allows you to safely push to failure with less risk. |
| [ ]  | **4. Side Lateral Raises**         | 4    | 12-15 |        | **Increased volume here.** This is the key movement for shoulder width. Give it an extra set.                                |
| [ ]  | **5. Triceps Pushdowns**           | 3    | 10-12 |        | A great way to isolate the triceps and warm up the elbows before the next movement.                                          |
| [ ]  | **6. Overhead Triceps Extensions** | 3    | 10-12 |        | Hits the long head of the triceps, which is crucial for overall arm size.                                                    |
| [ ]  | **7. Face Pulls**                  | 3    | 15-20 |        | A high-rep finisher to pump blood into the rear delts and external rotators, promoting health and recovery.                  |

### 🟩 Week B: The "Chest Priority" Push Day (Optimized Flow)

This keeps chest as the main focus but intelligently reorganizes the exercises to manage fatigue.

| Done | Exercise                        | Sets | Reps  | Weight | Notes / Rationale                                                                                                                     |
| ---- | ------------------------------- | ---- | ----- | ------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| [ ]  | **1. Barbell Flat Bench Press** | 4    | 6-8   |        | Your primary strength focus for the chest. Keep it first.                                                                             |
| [ ]  | **2. Incline Dumbbell Press**   | 3    | 8-10  |        | Continues to target the chest, especially the upper fibers.                                                                           |
| [ ]  | **3. Side Lateral Raises**      | 4    | 12-15 |        | **Strategic rest for pressing muscles.** This gives your triceps and front delts a break before they're needed again for OHP.         |
| [ ]  | **4. Seated Dumbbell OHP**      | 3    | 8-10  |        | **Better when fatigued.** A seated version requires less stabilization, allowing you to focus on the shoulders safely after benching. |
| [ ]  | **5. Weighted Dips**            | 3    | 8-12  |        | The primary triceps compound movement. Done here while you still have some energy.                                                    |
| [ ]  | **6. Cable Triceps Pushdowns**  | 2-3  | 12-15 |        | A finisher to pump up the triceps and ensure all fibers are fatigued.                                                                 |
| [ ]  | **7. Face Pulls**               | 3    | 15-20 |        | The perfect "cool down" exercise to balance out all the pressing and protect your shoulders.                                          |

### 🔹 Notes
- Perform **each movement with control**, focus on full range of motion.  
- Adjust intensity so you are **warm but not fatigued** at the end of the warmup.  
- Use this warmup before any push, pull, or legs session.
