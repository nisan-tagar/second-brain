Your financial life,
on your own server.

Goaldy is self-hosted personal finance software — accounts, budgets, and long-term planning in one Docker container you control. No cloud subscription, no OAuth, no one else holding your transaction history.

Try the Live Demo

Your data on someone else's server

Most personal finance apps store your transaction history on their own infrastructure. Goaldy stores it on yours.

A breach is their problem, and yours

Your account history, balances, and spending patterns sit on infrastructure you have no say in securing.

Companies change, shut down, get acquired

Free tiers end. Pricing changes overnight. A hosted app can lock you out or disappear entirely — a file you own cannot.

One file, entirely yours

Goaldy's entire database is a single SQLite file in a Docker volume. Back it up, move it, delete it — no permission required.

What it actually does

Buxfer's depth. None of the lock-in.

Net worth, decomposed

Every account — checking, investments, real estate, retirement — grouped by how liquid it actually is, not just what type it is.

Plan for what's coming

A household planning simulator projects your balance decades out, flags the years your savings can't cover, and tells you what to save each month to fix it.

Categorize once, forget it

A rules engine tags new transactions automatically the moment they arrive, based on conditions you define — no methodology forced on you.

See it running first

A public, read-only demo runs the real app against a seeded household — accounts, budgets, a household plan. Log in with password demo. Every field you'd normally change is disabled — nothing you do there is saved, and the data resets to a fresh fixture on every release.

Open the Live Demo
# set a first-boot password, then bring it up
ADMIN_PASSWORD=changeme docker compose up -d

Run it yourself

One Docker command, one image, one SQLite file in a named volume. Backups are a single docker compose cp. Upgrades pull the next tagged image and restart — your data volume is untouched.
